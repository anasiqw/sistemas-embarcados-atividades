Como funciona
O sistema funciona por meio de um Arduino Uno, que controla os componentes eletrônicos de acordo com a programação desenvolvida.

Ao iniciar o sistema, o Arduino executa o código e realiza as ações programadas. As entradas e condições do circuito provocam mudanças de estado, fazendo com que os componentes respondam conforme o funcionamento esperado.
