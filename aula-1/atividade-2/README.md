Componentes utilizados
- Arduino Uno
- Protoboard
- 2 botões
- 1 LED
- 1 buzzer
- Resistores
- Fios jumper
Como funciona
O sistema de alarme possui três estados:
1. DESATIVADO: O sistema fica desligado, com o LED apagado e o buzzer sem emitir som.
2. ATIVADO: Ao pressionar o botão de ativação, o sistema começa a monitorar possíveis detecções.
3. ALERTA: Quando o botão de detecção é pressionado, o LED acende e o buzzer começa a emitir som.
Para desligar o alarme, o botão de desativação é pressionado, fazendo o sistema retornar ao estado DESATIVADO.
Testes realizados
Teste 1 — Ativação
- Entrada testada: Pressionar o botão de ativação.
- Resultado esperado: O sistema passa para o estado ATIVADO.
- Resultado observado: O sistema começa a monitorar possíveis detecções.
Teste 2 — Detecção
- Entrada testada: Pressionar o botão de detecção.
- Resultado esperado: O LED acende e o buzzer toca.
- Resultado observado: O sistema entra no estado ALERTA.
Teste 3 — Desativação
- Entrada testada: Pressionar o botão de desativação.
- Resultado esperado: O sistema retorna ao estado DESATIVADO.
- Resultado observado: O LED apaga e o buzzer para de tocar.
Conclusão
A atividade permitiu desenvolver um sistema de alarme utilizando Arduino Uno, aprendendo sobre entradas e saídas digitais e o funcionamento de uma máquina de estados.
